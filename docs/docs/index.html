PUBLIC BETA 0.9 · FIRMWARE STAGE 5.10

Dreamcast Bluetooth + Virtual VMU

A NiceMCU ESP32 Dreamcast controller adapter combining BlueRetro Bluetooth input, a persistent 128 KiB virtual VMU, automatic microSD backup and a live 2.8" status display.

Flash Beta 0.9 Quick start GitHub source ☕ Buy me a coffee

Beta 0.9 power warning

Power the NiceMCU from USB-C and leave the Dreamcast controller-port +5 V wire disconnected.

Controller-port power is being tested separately and is not part of the public Beta 0.9 wiring.

What works

  • Bluetooth controller input via BlueRetro
  • Persistent 128 KiB virtual VMU
  • Real game save/load and power-cycle retention
  • Automatic SD VMU backup on cold boot
  • VMU:WRITING / VMU:SAVED feedback
  • SD:BACKUP OK status
  • Animated Dreamcast-style status display

Tested hardware

  • NiceMCU-32S-DEV 2.8" IPS
  • Original ESP32, 4 MB flash
  • ST7789 240×320 display
  • Onboard microSD slot
  • Single Dreamcast controller-port Maple connection

Tested cable wiring

RED → GPIO21
WHITE → GPIO22
GREEN → GND
COPPER/shield → GND
BLUE/+5 V → DISCONNECTED

Cable colours can vary. Verify the signals on your own cable before wiring.

Install in the browser

Use current Chrome or Edge on a desktop computer. Connect the NiceMCU over USB-C, then open the web flasher.

Open Web Flasher Wiring & safety Troubleshooting

The Beta 0.9 web flasher is a factory installation and can erase existing internal VMU saves and Bluetooth pairing data.

VMU backup

Runtime VMU data lives in internal flash. On cold boot the firmware can rotate the previous SD image to /VMU/BACKUP/PREV.BIN and copy the current VMU to /VMU/MC.BIN.
