# Beta Tester Checklist

Please report:

- exact NiceMCU board/revision
- Dreamcast region/model if known
- controller model
- microSD card size/format
- whether first factory flash succeeded
- whether BT changes to CONNECTED
- whether Dreamcast sees the virtual VMU
- whether VMU format succeeds
- whether a game can save and reload
- whether save survives complete power loss
- whether cold boot reports SD:BACKUP OK
- any controller lag, display glitches, resets or corrupted saves

Useful serial-monitor baud: 921600.
