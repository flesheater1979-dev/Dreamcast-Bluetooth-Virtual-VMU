# Publishing Checklist

Before putting this beta on a public GitHub release:

- [ ] Add your preferred project name/maintainer handle to README if desired.
- [ ] Keep `LICENSE-BLUERETRO-APACHE-2.0.txt`.
- [ ] Keep the BlueRetro attribution and upstream link.
- [ ] Keep the Beta 0.9 USB-power / +5 V warning prominent.
- [ ] Do not publish a full 4 MB dump from a personally used board; it can contain pairings/config/saves.
- [ ] Publish the clean build-output firmware included here instead.
- [ ] Upload the release ZIP and optionally enable GitHub Pages for `web-flasher/`.
- [ ] Ask testers to include the beta tester checklist in bug reports.
- [ ] Do not call controller-port power supported until the PTC + Schottky power revision is tested.
