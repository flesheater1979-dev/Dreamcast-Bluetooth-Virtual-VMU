Dreamcast Bluetooth + Virtual VMU

NiceMCU Beta 0.9 / firmware Stage 5.10

Power warning:

For Beta 0.9, power the NiceMCU from USB-C and leave the Dreamcast controller-port +5 V wire disconnected.

Before installing

  1. Use the tested NiceMCU-32S-DEV 2.8" original ESP32 board.
  2. Connect the board by USB-C.
  3. Use Chrome or Edge on desktop.
  4. Factory installation erases internal VMU saves and Bluetooth pairings.
  5. The microSD card is not formatted by the firmware.

Install Beta 0.9

This browser does not support Web Serial. Use current Chrome or Edge on desktop. Web Serial requires this page to be served from HTTPS or localhost.

After flashing, a cold boot may restart once while the VMU SD backup phase runs.

Wiring used by the tested cable

RED → GPIO21
WHITE → GPIO22
GREEN → GND
COPPER/shield → GND
BLUE/+5 V → DISCONNECTED

Cable colours can vary. Verify your own cable rather than assuming the colours match.
