Dreamcast Bluetooth + Virtual VMU Beta 0.9

NiceMCU-32S-DEV 2.8" / original ESP32 / firmware Stage 5.10

Read this first

Power the NiceMCU from USB-C. The Dreamcast +5 V wire is not used in this beta. Keep it disconnected and insulated.

Wire colours are not universal. The colours below are the development cable only.

DISCONNECTED

2 — Optional SD card

FAT32 recommended. 32 GB has been tested. The firmware creates /VMU/MC.BIN and rotates the previous copy to /VMU/BACKUP/PREV.BIN.

3 — Flash

Windows: open windows-flasher and run FLASH-WINDOWS.bat.

For a brand-new board choose Factory Install.

4 — Boot and pair

A cold boot may restart once. Pair your Bluetooth controller. The display should move from BT:PAIRING to BT:CONNECTED.

5 — VMU

Format the virtual VMU once if Dreamcast asks. Save a game and look for:

VMU:WRITING → VMU:SAVED → VMU:READY

6 — Confirm persistence

Power everything off completely, reconnect it, and confirm the game save is still present.

Expected with a working SD card: SD:BACKUP OK

More detail: docs/QUICK-START.md and docs/TROUBLESHOOTING.md.
